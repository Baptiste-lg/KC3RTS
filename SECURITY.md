# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository. Include reproduction
steps, affected versions and any relevant logs. Do not include real player
credentials or production secrets.

## Scope

The server is authoritative. Client-supplied positions, resources, ownership
and simulation results must be validated by the server. KC3 credentials and
internal service addresses must never be sent to the browser or committed.
